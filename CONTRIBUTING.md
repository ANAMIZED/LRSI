# Contributing to LRSI

Thank you for contributing.

1. Keep changes small and focused.
2. Never bypass the LRSI Runtime Core self-modification boundary.
3. Update README.md and AGENTS.md when public surfaces change.
4. Ensure `bash scripts/verify.sh` and `pytest -q` pass.
5. Prefer evidence-gated, reversible improvements.

By contributing you agree that your contributions will be licensed under the Apache License 2.0.
